PASO 1: CREAR CUENTA EN GITHUB (1 minuto)
═════════════════════════════════════════════════════════════════
1. Ve a: https://github.com/signup
2. Rellena: email, contraseña, username
3. Confirma tu email
4. ¡Listo!

PASO 2: CREAR REPOSITORIO (1 minuto)
═════════════════════════════════════════════════════════════════
1. Ve a: https://github.com/new
2. Nombre: nexusmatch
3. Descripción: Gaming matching app
4. Haz clic en "Create repository"
5. Verás una pantalla con instrucciones... IGNORA TODO
6. Solo copia la URL del repo (empieza con: https://github.com/TU_USERNAME/nexusmatch.git)

PASO 3: SUBIR CÓDIGO A GITHUB (2 minutos)
═════════════════════════════════════════════════════════════════
1. Abre Command Prompt (cmd.exe) como Administrador
2. Navega a tu carpeta outputs:

3. Ejecuta estos 5 comandos (copia y pega uno por uno):

   git init
   git add .

   git branch -M main

PASO 4: DESPLEGAR EN VERCEL (1 minuto)
═════════════════════════════════════════════════════════════════
1. Ve a: https://vercel.com/signup
2. Haz clic en "Continue with GitHub"
3. Autoriza Vercel para acceder a tu GitHub
4. Haz clic en "Import Project"
5. Busca "nexusmatch" y haz clic
6. Presiona "Deploy"
7. ¡ESPERA 1-2 MINUTOS!
8. Verás un enlace como: https://nexusmatch-XXXXX.vercel.app

ESE ES TU LINK. ¡Abrelo en el navegador y tu app estará corriendo!
